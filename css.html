Каскадні таблиці стилів CSS

Частково про CSS зазначалось у попередньому модулі

рекомендований спосіб додавати стилі для - це окремий файл, що підключається за допомогою тегу link у заголовку сторінки. Суть файлу - це послідовне застосування стилів для групп предметів, які потрапляють до селекторів. Можна казати, що кожна команда CSS-файлу має структуру 

        знайти все, що відповідає такому то селектору {
            і застосувати
            до нього даний
            набір стилів
        }

термін "каскадний" - стверджує те, що кожна наступна команда буде поєднуватися с поперднім

Основні селектори

Селектор Значення
img Всі елементи що мають тег <img />
* Всі елементи
.middle всі елементи в яких зазначений class="middle"
.selector-table th всі елементи <th> які знаходяться в середині елементів з class ="selector-table". взагалі, пробіл між селекторами означає "в середині" пробілом можуть розділятись і інші види селекторів. Наприклад, "p b" - всі теги <b> в середині параграфів (<p>); ".bold .small" - всі елементи с тегом "small" в середині тега "bold"
p, b Кома позначає "та" поєднання отже спільни стилі для двох (і більше) селекторів
