HTML = Hyper Text Markable Language - Гіпертекстова мова разметка
=======
commit - певне збереження, необхідно ввести повідомлення(назву)
push - передати commit або коміти до віддаленого сховища. В данному разі гітхаб
pull - витягнути комміт с віддаленого сховища до локального проекта 
sync - сінхронизуватись(витягнути та передати)
clone - створення локального проекту з віддаленого репозіторію
publish - створення віддаленого репозіторія з локального проекту
(public - загальнодоступний, private - прихований для інших)
