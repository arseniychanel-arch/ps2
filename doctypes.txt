Витяг: Типи та версії HTML/XHTML у декларації <!DOCTYPE>

================================================================================



Декларація <!DOCTYPE> (Document Type Definition) — це перша інструкція на початку 

HTML-документа. Вона повідомляє веб-браузеру, за якими стандартами інтерпретувати 

код, щоб уникнути переходу в режим сумісності (Quirks Mode).



--------------------------------------------------------------------------------

1. HTML5 (Сучасний стандарт)

--------------------------------------------------------------------------------

Сучасна універсальна декларація. Не містить посилань на зовнішні DTD-файли, 

є лаконічною та не чутливою до регістру символів.



<!DOCTYPE html>



--------------------------------------------------------------------------------

2. HTML 4.01

--------------------------------------------------------------------------------

Використовує посилання на DTD (Document Type Definition) та має 3 варіанти:



* Strict (Суворий) — містить лише чистий HTML без застарілих тегів та 

  атрибутів оформлення:

  <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN" "http://www.w3.org/TR/html4/strict.dtd">



* Transitional (Перехідний) — дозволяє використовувати застарілі теги 

  для зворотної сумісності:

  <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">



* Frameset (Фреймовий) — використовувався для документів, що розбивалися на фрейми:

  <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Frameset//EN" "http://www.w3.org/TR/html4/frameset.dtd">



--------------------------------------------------------------------------------

3. XHTML 1.0

--------------------------------------------------------------------------------

Версія HTML, що підпорядковується жорсткішим правилам синтаксису XML:



* XHTML 1.0 Strict:

  <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">



* XHTML 1.0 Transitional:

  <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">



* XHTML 1.0 Frameset:

  <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Frameset//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-frameset.dtd">



--------------------------------------------------------------------------------

4. XHTML 1.1

--------------------------------------------------------------------------------

Модульна версія XHTML для розширення іншими мовами розмітки (MathML, SVG):



<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN" "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">
